FlashTeX v0.2.0 is the first release with the new engine: a port of pdfTeX
to Rust that typesets as pdflatex does. It covers the changes since v0.1.9
(2026-09-26), about 520 merged pull requests.

## The new engine

- FlashTeX now ships a pdfTeX-compatible engine. It is translated from
  Knuth's `tex.web` and `pdftex.web` with TeX Live's change files, and it
  passes Knuth's trip test and e-TeX's etrip test.
- pdfTeX's font, image and PDF code is ported too: Type 1, Type 3/PK,
  TrueType and OpenType fonts, PNG/JPEG/PDF images, and SyncTeX.
- Each night it is checked against pdflatex, over fixtures, arXiv papers,
  templates, TeX Live package documents and a corpus of about 5,000
  documents. Infinite Descent, a 592-page book, comes out the same as
  pdflatex's.
- `bibtex` and `makeindex` are now built in (Rust ports). They run inside the
  engine and from `\write18`, with no TeX Live install.
- `\write18` is restricted by default, as in TeX Live.

## Instant preview

- One engine process stays running for each open document. After an edit it
  starts again from a saved point close to the edited page, not from the
  start of the document. Preamble edits also restart part-way through.
- Reopening a document is faster: the last state is saved on disk, so a
  reopen often needs one pass, not two or three.
- Tested for typing at up to 200 words per minute, with a latency target for
  the edited page.

## Mac app

- **Engine choice.** You can turn on the new engine for one document (the
  status bar's engine menu, or View > Engine for This Document) or for all
  documents (Settings > Compile). New documents still use the previous
  engine by default. If the new engine cannot typeset a project the way the
  previous engine does, the app uses the previous engine and tells you.
- **New-engine preview.** Zoom with sharp tiles, forward and reverse search,
  clickable hyperref links, the page under the caret marked, page labels,
  dark preview, VoiceOver page text and a Pages rotor. Export PDF and Print,
  bibliographies, indexes and package fetching all work with it.
- **Unicode mode.** Documents that need `fontspec` or `unicode-math` run in a
  XeLaTeX-compatible engine (`flashtex-host-unicode`), chosen per document.
  Unicode mode also works with no TeX Live installed.
- **Performance modes.** Settings > Performance: Low Memory, Balanced or
  High Performance. You can switch while a document is open.
- **Editor.** The project sidebar shows a folder tree. You can paste or drop
  an image to make a figure, choose editor themes, and use hybrid conceal
  (`\alpha` shows as α until the caret reaches it). The TeXpand abbreviation
  engine is in too, off by default. You can preview a single `\include`
  chapter (LaTeX's `\includeonly`). Settings has a delay for dimming stale
  pages. New windows open on a blank article.
- **Live Share** (preview, off by default) lets people edit together, with
  presence, invites and approval.
- **Speed and memory.** Typing no longer waits on work over the whole
  document. Leaks are fixed, including one in the preview that kept every
  page image (up to 9.6 GB). Memory use on large documents is much lower,
  and the app trims its caches under memory pressure.

## Command line

- `flashtex-v3` runs `build`, `check` and `watch` on the new engine and shows
  progress on a terminal. `--mode`, `% !TEX program` and a `[project]`
  setting choose the engine.
- The CLI tarball ships `flashtex-v3` with its engine host, `flashtex-host`.

## No TeX Live needed

- A TeX Live 2026 bundle is published as release assets
  (`texbundle-tl2026-*`). The new engine compiles from it with no TeX Live
  installed, including bibliography and index styles.

## Previous engine

- The previous engine is frozen and gets fixes only. Fixes in this release:
  TikZ and pgfplots plots, amsmath `aligned`, amsthm spacing, `\sqrt[n]`,
  `\binom`, siunitx, fancyhdr, minipage, multicolumn, and side-by-side
  authors.
