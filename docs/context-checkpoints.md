# Durable context checkpoints

Follow AGENTS.md context thresholds using actual telemetry. Record the following
in the agent's owned report/handoff path before invoking supported compaction:

- Task and assignment revision; exact branch, HEAD, worktree and owned paths.
- Dirty files, completed behavior, tests with exact evidence and known limitations.
- Running command/session IDs, uncertain publication journals and pending messages.
- Immediate next steps, dependency SHAs, current authority, staffing and billing rules.

Do not overwrite another agent's checkpoint or include credentials. Resume from
this record plus freshly fetched authority/control, preserving unfinished work.
Compaction does not terminate the agent or authorize Commander replacement. Lack
of a compaction tool or context percentage must be reported honestly, not replaced
with a guessed percentage or a forced restart. Parent leads propagate this rule
without adding workers or waking stopped workers.
