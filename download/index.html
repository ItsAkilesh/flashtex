  • macOS
    Requires macOS 14 Sonoma or later
    Apple Silicon 13.0 MB Intel not yet available

    A disk image containing FlashTeX.app, with the Rust compiler, PDF writer and capture bridge bundled inside. No TeX distribution required.

  • Command line
    macOS · Apple Silicon
    $ curl -fsSL https://flash-tex.github.io/flashtex/install.sh | sh

    Downloads the release, checks its SHA-256, and copies FlashTeX.app into /Applications. Because it doesn't go through a browser, macOS won't ask you to approve the app on first launch. Read the script.

    Compare against shasum -a 256 ~/Downloads/FlashTeX.dmg.

  • Windows & Linux
    Not available

    FlashTeX is a native Mac app, written in Swift on top of a Rust engine. Other platforms aren't on the roadmap.

Opening the app the first time

This build is ad-hoc signed but not yet notarized by Apple, so a browser download is quarantined and macOS asks you to approve it once.

  1. Open FlashTeX.dmg and drag FlashTeX into Applications.
  2. Right-click FlashTeX in Applications, choose Open, then confirm.
  3. If macOS says the app is damaged, run xattr -dr com.apple.quarantine /Applications/FlashTeX.app and open it again.
  • Build it yourself
    Latest main, same bundle as the release
    1. Clone the repository
      $ git clone https://github.com/flash-tex/flashtex.git $ cd flashtex
    2. Build the Rust engine and helpers
      $ for c in compiler pdf bridge render-pipeline; do cargo build --release --manifest-path crates/$c/Cargo.toml done
    3. Package, install and open
      $ ./apps/mac/scripts/make-app.sh --install --open

    A locally built app isn't quarantined, so it opens without the approval step. --install copies it to ~/Applications; add --dmg to produce a disk image too.
