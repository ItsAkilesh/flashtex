# Producer delta r2 review

Exact proposal: `96e95628dcda6c64c1447fded6cf7bd6eb628daf`, `crates/render-pipeline/docs/proposals/display-list-v2-delta.md`. Read-only review; no activation or implementation approval.

1. **Stale installation conflicts with authority and residency (§6.1–6.3).** The proposal installs stale-by-ticket results as reconstruction bases while retaining a newer painted frame. Existing strict `CurrentHelper` binding refuses stale identities against fresh caller state. Painted A + installed stale B + candidate C also contradicts the claim that the painted frame always equals installed and there are only two retained snapshots. Preserve stale refusal, or separately propose a non-authoritative reconstruction cache and account for all retained frames/resources. A hidden-pane installation also needs reconciliation with the pane-hidden clearing event.
2. **Snapshot budget measures the wrong object (§6.2).** The consumer uses received line length for `MAX_SNAPSHOT_BYTES`; a small delta is not the serialized size of its reconstructed full list. Charge the reconstructed target and peak old/new/callback/resource residency, independently of input line bounds. The explicit model-overhead measurement caveat is honest but does not itself provide a bounded decoded/resource allocation policy.
3. **Diagnostic completeness is not established by a sender-supplied digest (§5.5).** Omitting a diagnostic and recomputing the list digest remains internally consistent. Fresh-full producer equivalence must establish completeness; existing core does not compare the v1/v2 diagnostic sequences. Do not state that omission necessarily gives `delta_list_digest_mismatch`.
4. **`PartialEq` does not imply exact paint representation equality (§5.2).** Positive and negative floating zero compare equal but have different binary64 canonical bits and potentially different JSON. Use the defined exact representation for classification or explicitly constrain the representation with adversarial vectors. The Python illustrative semantic reconstruction is not proof of actual producer JSON equality.
5. **Name the actual full validation path (§5.4/6.1).** Generic rendering-core validation is static TrueType; actual CFF requires explicit `PipelineCff` source/resource binding. A nonexistent/default `validate_display` shortcut is not that acceptance gate. Existing helper source/currentness and export/hit authority must remain separate from digest consistency.
6. **Scope cancellation (§6.3).** A producer request protocol without a cancel command does not remove helper cancellation/supersession and late callback obligations. State which layer retains or clears an acknowledged base after each event.

The installed acknowledgement is now distinct from output admission/write, complete headers and resource closure are explicit, and §8 correctly preserves oversized full-resync refusal. Keep these improvements. No small delta authorizes omission of full v1 output or bypasses its cost/limit. Existing owners must resolve the blockers before any wire switch.
