What's actually different

Built for the document you're staring at right before it's due.

§1 Compiler

An engine, not a wrapper

FlashTeX's compiler is written from scratch in Rust — it tokenizes, expands macros, and lays out glue and boxes itself. No TeX distribution runs behind the scenes; unsupported constructs get an explicit diagnostic instead of a silent guess.

§2 Preview

Sub-200ms, every keystroke

Edits reuse the previous layout incrementally instead of recompiling the whole document, so the preview updates as fast as you type — and click any rendered word to jump straight to its exact byte range in the source.

§3 Capture

Draw it, get LaTeX back

Sketch a derivation on iPad with Pencil, or photograph a page of handwritten proof. Grok converts it to editable LaTeX at a destination you pin on Mac — you review the diff before anything lands in your source.

§4 Recovery

One typo doesn't cost the page

A malformed command or an unclosed brace recovers locally: you get a precise diagnostic and the rest of the document keeps rendering, instead of staring at a blank preview until you find the missing }.

Errors that point somewhere

The diagnostic names the byte, not just the line.

Every diagnostic carries the exact source range it came from — the editor underlines it, the message explains what recovery was applied, and the rest of your proof keeps compiling underneath it.

Distribution

Install FlashTeX

Download the prebuilt app, or build it yourself from source. Both give you the same bundle: the Rust compiler, PDF writer and capture bridge ship inside it, so there's no TeX distribution to install.

Recommended

FlashTeX 0.1.0 for Mac

FlashTeX.dmg · 10.4 MB · macOS 14+ · Apple Silicon

Download FlashTeX.dmg All releases & notes →
  1. Open the DMG and drag FlashTeX into Applications.
  2. Right-click the app → Open, then click Open in the dialog. This is only needed once: the build is ad-hoc signed, not notarized, so Gatekeeper asks the first time.
  3. Open any .tex file with File → Open. The preview compiles as you type, and clicking rendered text jumps to its source.
If macOS says the app is damaged

That's the quarantine flag on an unnotarized download, not a broken file. Clear it once in Terminal, then open normally:

xattr -dr com.apple.quarantine /Applications/FlashTeX.app

Or build from source

Terminal — zsh
1. Clone the repository
$ git clone https://github.com/flash-tex/flashtex.git $ cd flashtex
2. Build the Rust helpers
$ cargo build --release \ --manifest-path crates/compiler/Cargo.toml $ cargo build --release \ --manifest-path crates/pdf/Cargo.toml $ cargo build --release \ --manifest-path crates/bridge/Cargo.toml
3. Package and launch the app
$ ./apps/mac/scripts/make-app.sh --open --install
First launch

The bundle is ad-hoc signed, so Gatekeeper will refuse a plain double-click the first time. Right-click FlashTeX.app in ~/Applications → Open → confirm once, and it launches normally after that.

--install copies the built app into ~/Applications; drop it if you'd rather run it straight from apps/mac/build/.
